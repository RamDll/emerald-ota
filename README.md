# emerald-ota

Update lists for the system Updater of the unofficial LineageOS 24 build for POCO M6 Pro / Redmi Note 13 Pro 4G
(`emerald`). The phone reads `emerald/<its build number>.json`; the files themselves are attached to the
[releases](https://github.com/RamDll/emerald-ota/releases).

Списки обновлений для приложения «Обновление системы» неофициальной сборки LineageOS 24 для POCO M6 Pro /
Redmi Note 13 Pro 4G. Телефон сам читает `emerald/<номер своей сборки>.json`, файлы лежат в релизах.
Вручную скачивать отсюда не нужно: полные образы и инструкция — в теме на 4PDA.
